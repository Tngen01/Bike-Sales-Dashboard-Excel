# Bike Sales Dashboard Analysis

## Overview

This project analyzes customer demographic and purchasing data to identify factors that influence bike purchases. Using Excel, the data was cleaned, transformed, and visualized through an interactive dashboard to uncover meaningful business insights.

The dashboard helps understand how customer characteristics such as income, age, commute distance, and demographics impact purchasing behavior.

---

## Dataset

The dataset contains customer information including:

* Customer ID
* Marital Status
* Gender
* Income
* Number of Children
* Education
* Occupation
* Home Ownership
* Number of Cars
* Commute Distance
* Region
* Age
* Bike Purchase Status

---

## Project Workflow

### Data Cleaning

* Checked for missing values
* Standardized data formats
* Validated customer records

### Data Analysis

* Analyzed customer income levels
* Examined age distribution
* Studied commute distance patterns
* Compared purchasing behavior across demographics

### Dashboard Development

Created an interactive dashboard to visualize:

* Average Income by Gender and Purchase Status
* Customer Age Brackets
* Commute Distance Analysis
* Bike Purchase Trends

---

## Business Questions Answered

1. How does income influence bike purchases?
2. Which age groups are more likely to purchase bikes?
3. Does commute distance affect purchasing decisions?
4. How do purchasing patterns differ between genders?
5. What customer segments have the highest purchase rates?

---

## Key Insights

* Customers with higher income levels showed a greater tendency to purchase bikes.
* Certain age groups demonstrated stronger purchasing behavior.
* Commute distance influenced the likelihood of purchasing a bike.
* Purchasing trends varied across demographic groups.
* Customer segmentation helped identify potential target audiences.
